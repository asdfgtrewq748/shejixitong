## 3. 评价点生成逻辑

### 3.1 评价点类型
系统生成三类评价点：

#### (1) 钻孔点 (type="borehole")
- 直接使用上传的钻孔坐标
- 数量: 等于钻孔数量

#### (2) 工作面边界点 (type="workface_boundary")
- 沿工作面四条边界，按步长生成
- 生成逻辑:
```python
for 每条边 in 工作面四边:
    edge_length = 边长
    num_steps = int(edge_length / step_size)
    for k in range(num_steps + 1):
        t = k / num_steps
        点坐标 = 起点 + t * 边向量
```

#### (3) 工作面内部点 (type="workface_interior")
- 在工作面边界框内按网格生成
- 只保留落在多边形内部的点
- 生成逻辑:
```python
min_x, min_y = 工作面最小坐标
max_x, max_y = 工作面最大坐标

x = min_x + step_size
while x < max_x:
    y = min_y + step_size
    while y < max_y:
        if is_point_in_polygon(x, y, workface):
            添加评价点(x, y)
        y += step_size
    x += step_size
```

### 3.2 评价点总数估算
```
总数 ≈ 钻孔数 + 4×(边长/步长) + (面积/步长²)
```

## 4. 参数计算与插值

### 4.1 地质参数插值 (IDW反距离加权)

对于每个评价点，通过钻孔数据插值获取地质参数：

```python
def idw_interpolation(x, y, borehole_data, field_name, power=2.0):
    """
    IDW插值公式: V = Σ(wi × vi) / Σ(wi)
    权重: wi = 1 / distance^power
    """
    weights = []
    values = []

    for borehole in borehole_data:
        dist = sqrt((x - borehole.x)² + (y - borehole.y)²)

        if dist < 0.1:  # 非常接近钻孔点
            return borehole[field_name]

        weight = 1.0 / (dist ** power)
        weights.append(weight)
        values.append(borehole[field_name])

    return sum(w * v for w, v in zip(weights, values)) / sum(weights)
```

插值的参数:
- `Ti` - 目标层厚度
- `Ei` - 弹性模量
- `Hi` - 间距
- `Di` - 埋深
- `coal_thickness` - 煤层厚度

### 4.2 开采参数确定

#### (1) 采高 Mi 的确定逻辑 (关键!)
```python
def _determine_mi(x, y, coal_thickness):
    """
    采高Mi的判别逻辑:
    1. 评价点在工作面边界上 → Mi = 0
    2. 评价点在工作面内部 → Mi = 设定的开采采高 (强制使用)
    3. 评价点在工作面外部 → Mi = 0

    注意: 工作面内部不使用插值的coal_thickness，而是强制使用设定采高
    这是为了确保工作面内ODI一致，避免因钻孔稀疏导致的插值偏差
    """
    for workface in workfaces:
        if is_point_on_boundary(x, y, workface):
            return 0.0  # 边界上

        if is_point_in_polygon(x, y, workface):
            return self.mining_height  # 工作面内部，强制使用设定采高

    return 0.0  # 工作面外部
```

#### (2) 工作面宽度 lpi
```python
def calculate_workface_width(workface_coords):
    """
    工作面宽度 = 相对两边的平均距离
    通常取较短边的长度
    """
    # 计算四边长度
    edges = [边1长度, 边2长度, 边3长度, 边4长度]
    # 取较短对边的平均值
    return (min(edges[0], edges[2]) + min(edges[1], edges[3])) / 2
```

#### (3) 区段煤柱宽度 lci
- 如果只有一个工作面: lci = 0 或用户设定值
- 如果有多个工作面: lci = 相邻工作面之间的最短距离

#### (4) 垮落角 δi
- 固定值: 75° (默认)
- 可由用户设定

### 5.4 9个响应指标计算

```python
def calculate_9_indicators(params, weight_matrix):
    """
    矩阵乘法: Result_ind = X × W

    params: 参数向量 (5或8维)
    weight_matrix: 权重矩阵 (5×9或8×9)

    返回: 9个指标向量
    """
    return np.dot(params, weight_matrix)
```

**9个响应指标含义:**
| 序号 | 符号 | 含义 |
|------|------|------|
| 1 | Smax | 最大下沉量 |
| 2 | DSmax | 最大下沉梯度 |
| 3 | Kσ | 应力集中系数 |
| 4 | Dσmax | 最大应力梯度 |
| 5 | Aσ | 应力影响范围 |
| 6 | Hf | 导水裂隙带高度 |
| 7 | Kw | 渗透系数变化 |
| 8 | Bf | 破裂带宽度 |
| 9 | Af | 破裂影响范围 |

### 5.5 三类响应计算

```python
def calculate_three_responses(indicators):
    """
    将9个指标聚合为3类响应

    位移响应: wd = Smax + DSmax        (指标1+2)
    力学响应: wo = Kσ + Dσmax + Aσ      (指标3+4+5)
    水力响应: wf = Hf + Kw + Bf + Af    (指标6+7+8+9)
    """
    wd = indicators[0] + indicators[1]
    wo = indicators[2] + indicators[3] + indicators[4]
    wf = indicators[5] + indicators[6] + indicators[7] + indicators[8]

    return wd, wo, wf
```

### 5.6 ODI计算

```python
def calculate_odi(wd, wo, wf, scenario, apply_calibration=True):
    """
    ODI = α × wd + β × wo + γ × wf

    场景权重:
    - 地表下沉:    α=0.45, β=0.30, γ=0.25
    - 含水层扰动:  α=0.60, β=0.25, γ=0.15
    - 上行开采:    α=0.20, β=0.45, γ=0.35
    """
    SCENARIO_WEIGHTS = {
        "surface_subsidence":   {"wd": 0.45, "wo": 0.30, "wf": 0.25},
        "aquifer_disturbance":  {"wd": 0.60, "wo": 0.25, "wf": 0.15},
        "upward_mining":        {"wd": 0.20, "wo": 0.45, "wf": 0.35},
    }

    weights = SCENARIO_WEIGHTS[scenario]
    raw_odi = weights["wd"] * wd + weights["wo"] * wo + weights["wf"] * wf

    # 应用校准系数 (将原始ODI映射到0-1区间)
    if apply_calibration:
        calibration = SCENARIO_CALIBRATION[scenario]
        odi = raw_odi * calibration["scale"] + calibration["bias"]
    else:
        odi = raw_odi

    return odi
```

### 5.7 校准系数

```python
SCENARIO_CALIBRATION = {
    "surface_subsidence":   {"scale": 0.00501721, "bias": -0.68355928},
    "aquifer_disturbance":  {"scale": 0.00451917, "bias": -0.30262604},
    "upward_mining":        {"scale": 0.005,      "bias": -0.5},
}
```

校准公式: `ODI_calibrated = raw_ODI × scale + bias`

### 5.8 非开采区处理 (关键!)

```python
# 物理约束: 非开采区(Mi=0)无扰动，强制ODI为0
if Mi <= 0:
    odi = 0.0
```

**这确保工作面外部的ODI为0，颜色为蓝色。**

## 6. 等级划分与校准

### 6.1 ODI等级标准

| 等级 | ODI范围 | 下沉量范围 | 扰动程度 | 颜色 |
|------|---------|------------|----------|------|
| I级 | ≤ 0.045 | ≤ 0.30m | 轻微扰动 | 蓝色 #3b82f6 |
| II级 | 0.045 ~ 0.345 | 0.30 ~ 1.20m | 较弱扰动 | 黄色 #facc15 |
| III级 | 0.345 ~ 0.825 | 1.20 ~ 2.80m | 中等扰动 | 橙色 #fb923c |
| IV级 | 0.825 ~ 0.847 | 2.80 ~ 4.20m | 较强扰动 | 浅红 #f87171 |
| V级 | > 0.847 | > 4.20m | 强扰动 | 深红 #dc2626 |

### 6.2 等级判定函数

```python
def get_disturbance_level(odi):
    ODI_LEVELS = [
        {"level": 1, "odi_max": 0.045, "name": "I级", "meaning": "轻微扰动"},
        {"level": 2, "odi_max": 0.345, "name": "II级", "meaning": "较弱扰动"},
        {"level": 3, "odi_max": 0.825, "name": "III级", "meaning": "中等扰动"},
        {"level": 4, "odi_max": 0.847, "name": "IV级", "meaning": "较强扰动"},
        {"level": 5, "odi_max": 1.0,   "name": "V级", "meaning": "强扰动"},
    ]

    for level_info in ODI_LEVELS:
        if odi <= level_info["odi_max"]:
            return level_info

    return ODI_LEVELS[-1]  # V级
```

### 6.3 实测数据校准 (可选)

如果有实测下沉数据，系统可以自动校准ODI阈值:

```python
def recalibrate_levels(measured_data, odi_results):
    """
    基于实测数据重新校准ODI等级阈值

    1. 建立 实测下沉值 -> 计算ODI 的映射
    2. 根据下沉阈值 (0.30, 1.20, 2.80, 4.20) 反推ODI阈值
    """
    pairs = []  # (measured_subsidence, calculated_odi)

    for measured_point in measured_data:
        odi = idw_interpolation(measured_point.x, measured_point.y, odi_results, "odi")
        pairs.append((measured_point.value, odi))

    # 按实测值排序
    pairs.sort(key=lambda x: x[0])

    # 线性插值反推阈值
    subsidence_thresholds = [0.30, 1.20, 2.80, 4.20]
    new_odi_thresholds = []

    for th in subsidence_thresholds:
        new_odi = np.interp(th, [p[0] for p in pairs], [p[1] for p in pairs])
        new_odi_thresholds.append(new_odi)

    return new_odi_thresholds
```

│         [Smax, DSmax, Kσ, Dσmax, Aσ, Hf, Kw, Bf, Af]               │

                               │
                               ▼

│                       等级划分                                       │
├─────────────────────────────────────────────────────────────────────┤
│  ODI ≤ 0.045        → I级  (轻微扰动, 蓝色)                         │
│  0.045 < ODI ≤ 0.345 → II级 (较弱扰动, 黄色)                        │
│  0.345 < ODI ≤ 0.825 → III级(中等扰动, 橙色)                        │
│  0.825 < ODI ≤ 0.847 → IV级 (较强扰动, 浅红)                        │

                               │
                               ▼

│  2. 高斯模糊平滑 (Mi字段跳过)                                        │
│  3. 5级分区着色 (ODI字段) / 渐变着色 (其他字段)                      │

## 已知问题与待验证项

1. **Mi强制使用设定采高**: 工作面内部不使用插值煤厚，而是强制使用设定的开采采高。这是为了避免钻孔稀疏导致的插值偏差，但可能与实际情况有差异。

2. **校准系数来源**: 当前校准系数 `(scale=0.00501721, bias=-0.68355928)` 是基于验证数据拟合的，需要更多实测数据验证。

3. **5参数vs8参数模式**: 当前默认使用5参数拟合模式，8参数理论模式需要更多测试。

4. **前端插值精度**: 前端使用IDW+高斯混合插值，与后端计算结果可能有微小差异。

5. **ODI等级阈值**: IV级和V级阈值非常接近 (0.825 vs 0.847)，需要确认是否合理。
