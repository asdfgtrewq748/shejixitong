2.1 性能优化：点在多边形内判断加速
------------------------------------------------------------------------------

问题描述:
  当前在生成热力图时，对每个网格点(500x500=250000个)都进行射线法判断，
  时间复杂度为 O(resolution² × polygon_vertices)，导致生成图片耗时较长。

当前代码位置:
  backend_python/routers/disturbance.py: get_heatmap_image() 函数
  第869-874行的双重循环

优化方案:
  使用 matplotlib.path.Path 或 shapely 库进行向量化判断：

  ```python
  from matplotlib.path import Path
  # 或使用 shapely
  from shapely.geometry import Polygon, Point
  from shapely.vectorized import contains

  # 方案1: matplotlib.path (推荐，无额外依赖)
  if workface_coords and len(workface_coords) >= 3:
      poly = np.array([[p.get("x", 0), p.get("y", 0)] for p in workface_coords])
      path = Path(poly)

      # 将网格点展平为 (N, 2) 数组
      points = np.column_stack([grid_xx.ravel(), grid_yy.ravel()])

      # 向量化判断 (一次性判断所有点)
      inside = path.contains_points(points).reshape(grid_z.shape)

      # 应用掩膜
      grid_z = np.where(~inside, np.nan, grid_z)

  # 方案2: shapely (功能更强大)
  from shapely.geometry import Polygon
  from shapely.vectorized import contains

  poly = Polygon([(p["x"], p["y"]) for p in workface_coords])
  inside = contains(poly, grid_xx, grid_yy)
  grid_z = np.where(~inside, np.nan, grid_z)
  ```

预期效果:
  热力图生成时间从 5-10秒 降低到 0.5-1秒

2.2 插值算法优化：使用KD树加速IDW
------------------------------------------------------------------------------

问题描述:
  当前IDW插值对每个插值点遍历所有数据点，时间复杂度 O(n×m)，
  其中n为插值点数，m为数据点数。

当前代码位置:
  backend_python/utils/odi_calculator_v2.py: idw_interpolation() 函数

优化方案:
  使用 scipy.spatial.cKDTree 限制搜索范围：

  ```python
  from scipy.spatial import cKDTree

  class ODICalculatorV2:
      def __init__(self, ...):
          ...
          self._kd_tree = None
          self._kd_data = None

      def _build_kd_tree(self, bh_data: List[Dict]):
          """构建KD树用于快速邻域搜索"""
          if not bh_data:
              return
          coords = np.array([[p["x"], p["y"]] for p in bh_data])
          self._kd_tree = cKDTree(coords)
          self._kd_data = bh_data

      def idw_interpolation_fast(self, x: float, y: float, field: str,
                                   k: int = 8, power: float = 2.0) -> float:
          """使用KD树加速的IDW插值"""
          if self._kd_tree is None:
              return 0.0

          # 查询最近的k个点
          distances, indices = self._kd_tree.query([x, y], k=min(k, len(self._kd_data)))

          if np.isscalar(distances):
              distances = [distances]
              indices = [indices]

          weights = []
          values = []

          for dist, idx in zip(distances, indices):
              if dist < 0.1:
                  return self._kd_data[idx].get(field, 0)

              weight = 1.0 / (dist ** power)
              weights.append(weight)
              values.append(self._kd_data[idx].get(field, 0))

          total_weight = sum(weights)
          if total_weight == 0:
              return 0.0

          return sum(w * v for w, v in zip(weights, values)) / total_weight
  ```

预期效果:
  评价点计算速度提升 3-5倍

2.4 数据验证增强
------------------------------------------------------------------------------

问题描述:
  当前上传文件时缺乏严格的数据验证，可能导致计算错误或异常。

需要添加的验证:

  1. 钻孔坐标验证:
     - X, Y 坐标应为有效数值
     - 坐标范围应在合理地理范围内
     - 检测重复钻孔ID

  2. 工作面坐标验证:
     - 至少需要4个点形成闭合多边形
     - 点应按顺时针或逆时针顺序排列
     - 多边形不应自相交

  3. 地层数据验证:
     - 厚度应为正数
     - 弹性模量应在合理范围 (0.1-100 GPa)
     - 深度应单调递增

优化代码示例:
  ```python
  # backend_python/routers/disturbance.py

  def validate_workface_coords(coords: List[Dict]) -> Tuple[bool, str]:
      """验证工作面坐标"""
      if len(coords) < 4:
          return False, "工作面坐标至少需要4个点"

      # 检查坐标值有效性
      for i, p in enumerate(coords):
          x, y = p.get("x"), p.get("y")
          if x is None or y is None:
              return False, f"第{i+1}个点坐标无效"
          if not (-1e9 < x < 1e9 and -1e9 < y < 1e9):
              return False, f"第{i+1}个点坐标超出合理范围"

      # 检查多边形是否自相交
      from shapely.geometry import Polygon
      poly = Polygon([(p["x"], p["y"]) for p in coords])
      if not poly.is_valid:
          return False, "工作面多边形无效（可能自相交）"

      return True, "验证通过"
  ```

       // 根据比例计算实际坐标
